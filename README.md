
# Nithya Sri — Responsive Portfolio

A modern, responsive personal portfolio website developed as part of the **Junior Frontend Developer Internship — Week 1 Assignment**.

The project demonstrates the development of a responsive landing page using semantic HTML5, modern CSS, Flexbox, CSS Grid, media queries, and vanilla JavaScript.

## 📌 Internship Assignment

### Week 1: Responsive Landing Page Development

The objective of this assignment was to transform a self-designed wireframe into a fully functional responsive webpage.

The website was designed to work smoothly across:

- Desktop
- Tablet
- Mobile

The implementation focuses on clean structure, responsive layouts, usability, accessibility, and basic JavaScript interactivity.

## 🎯 Project Objective

The goal of this project was to build a personal portfolio landing page that demonstrates practical frontend development skills while presenting my engineering background, technical skills, projects, and professional journey.

The website was designed from a custom wireframe and implemented using standard web technologies without relying on frontend frameworks.
